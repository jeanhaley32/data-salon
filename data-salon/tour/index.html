One laptop that watches itself, heals itself, and knows the world around it.

Rodin is a headless AI agent living on an always-on ThinkPad T480, reachable only over a private Tailscale tunnel. It began as a plain message relay to a language model. It grew — one real problem at a time — into a self-hosted platform that monitors its own hardware, runs a Kubernetes cluster, indexes email into a vector database, watches the home network for devices phoning home, and routes its own alerts back through the model so the machine can react to events and report in. This is a tour of what's actually running. Every claim here was read off the live system.
